팔로워부터 활동 기록까지, 내 데이터로 차분하게 살펴보세요.

내 데이터는 내 브라우저에. 파일 분석은 이 브라우저에서 처리됩니다. 스냅샷·메모는 기기에 저장되며, 저장소가 없으면 메모리에만 남습니다. Google Drive 버튼을 사용할 때만 스냅샷·메모가 내 Drive로 전송됩니다. 익명 방문 수만 GoatCounter로 집계하며, 인스타그램 데이터는 절대 전송되지 않습니다.
인스타그램 데이터 받는 방법 다운로드 안내

메뉴 이름·위치는 앱 버전에 따라 조금 다를 수 있습니다. 대략적인 경로입니다.

  1. 인스타그램 앱 → 프로필 → ☰ → 설정
  2. 계정 센터 → 내 정보 및 권한
  3. 내 정보 다운로드 → 다운로드 또는 전송
  4. 일부 정보 선택 → 팔로워 및 팔로잉 체크. 활동 분석에는 좋아요, 댓글, 스토리 활동, 메시지도 선택
  5. 기기로 다운로드 → 기간: 전체 기간, 형식: JSON 선택 → 요청
  6. 준비 완료 알림(이메일)이 오면 zip을 다운로드해 아래에 올리세요.

          04 / ARCHIVE

          저장된 스냅샷 관리

            config.js의 Google 클라이언트 ID를 설정하면 동기화를 사용할 수 있습니다.

            Instagram Manager 내 데이터를 이해하는 작은 도구

            내 드라이브 어디에 저장되나요?

            1. 스냅샷은 내 드라이브의 보이는 폴더가 아니라 이 앱 전용 숨김 공간(appDataFolder)에 igfc_snapshots.json 파일 하나로 저장돼요.
            2. 내 드라이브 목록에는 보이지 않고, 다른 앱이나 다른 사람은 읽을 수 없어요. 이 앱도 드라이브의 다른 파일에는 접근할 수 없어요.
            3. 저장되는 내용은 스냅샷(날짜별 팔로워 아이디 목록)과 태그·메모예요. 비밀번호나 인스타그램 로그인 정보는 저장하지 않아요.
            4. 확인·삭제: drive.google.com → 오른쪽 위 톱니바퀴(설정) → 설정 → 앱 관리 → 이 앱의 ‘옵션’ → ‘숨겨진 앱 데이터 삭제’ (메뉴 이름은 Google 사정에 따라 조금 다를 수 있어요). 앱 연결 해제는 myaccount.google.com/connections (타사 앱 및 서비스)에서 할 수 있어요.
            5. 로그인할 때 ‘Google에서 확인하지 않은 앱’ 경고가 뜰 수 있어요. 개인이 만든 테스트 단계 앱이라 뜨는 것이고, ‘계속’을 눌러 진행하면 돼요.
